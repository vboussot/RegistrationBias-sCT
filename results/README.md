# Results

- `raw/Evaluations/`: the patient-level metrics of the paper, one
  `Metric_TRAIN.json` per model branch and region.
- `leaderboards/`: the public SynthRAD2025 test leaderboards of Tables 10 to 13.

`make tables` builds Tables 4, 9 and 14 to 19 from these metrics. The
files are described in `docs/RESULTS.md`.
